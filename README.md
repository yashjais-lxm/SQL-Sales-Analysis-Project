# 📊 SQL Sales Analysis Project

 Practical SQL Project for Business Data Analysis using PostgreSQL

 # 📌 Overview

This project demonstrates the use of **PostgreSQL** to analyze sales data and solve real-world business problems using SQL.

The project includes database design, table creation, data import, and analytical SQL queries ranging from beginner to advanced level. It showcases practical SQL techniques commonly used in data analytics to extract insights and support business decision-making.

---

# 🎯 Objectives

- Design a relational sales database
- Import data from CSV files
- Analyze sales performance using SQL
- Practice real-world business queries
- Build a professional SQL portfolio project
