# SQL Sales Analysis Project

## 📌 Project Overview
This repository contains end-to-end data analysis queries executed on a PostgreSQL database. It covers customer behaviors, sales trends, employee hierarchies, and performance metrics.

## 📁 Repository Structure
- `Dataset/`: Contains source CSV files (`Customers.csv`, `Orders.csv`, `Products.csv`, `Employees.csv`).
- `SQL/`: Contains structured `.sql` analytical scripts.
- `Images/`: Visualizations and query execution output.

## 🚀 Key SQL Concepts Demonstrated
- **Window Functions**: `LAG()`, `LEAD()`, `RANK()`, `DENSE_RANK()`, `NTILE()`, `FIRST_VALUE()`
- **CTEs & Recursive CTEs**: Customer segmentation and organizational hierarchy
- **Views & CTAS**: Reusable relational abstractions and summary reporting
- **Time-Series Analysis**: Month-over-Month (MoM) sales growth and order intervals
